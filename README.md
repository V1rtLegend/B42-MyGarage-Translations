# B42: My Garage - Community Translations

Community translation files for **B42: My Garage** for **Project Zomboid Build 42**.

Thank you to everyone who helps translate the mod!

## Russian Translation 🇷🇺

The Russian translation template is located here:

`media/lua/shared/Translate/RU/`

Please translate only the text values.

### Example

Original:

```json
"IGUI_MG_TireRack_Title": "Tire Rack"
```

Russian translation:

```json
"IGUI_MG_TireRack_Title": "Стеллаж для шин"
```

Please do **not** change:

- Translation keys
- File names
- JSON structure
- Folder structure

## How to contribute

You can contribute in either of these ways:

1. Download the repository, translate the files inside the `RU` folder, then send the completed folder back to me as a ZIP.

2. If you are familiar with GitHub, you can fork this repository and submit a Pull Request.
